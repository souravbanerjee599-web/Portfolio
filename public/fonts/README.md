# PP Telegraf Font Files

Drop the licensed PP Telegraf woff2 font files into this directory:

- `PPTelegraf-Ultralight.woff2`
- `PPTelegraf-Regular.woff2`
- `PPTelegraf-Medium.woff2`
- `PPTelegraf-Bold.woff2`

PP Telegraf is available at: https://pangram-pangram.com/products/pp-telegraf

The site falls back to **Space Mono** (loaded from Google Fonts) and will look correct without these files.
